# My Notification App (Wallet Speaker)

An Android application designed to listen to incoming payment and transaction notifications (such as eSewa and Khalti), process them, and provide spoken audio announcements in Nepali.

## Features
- **Notification Listening**: Automatically captures transaction notifications from supported digital wallets (eSewa, Khalti).
- **Text-to-Speech (TTS)**: Announces transaction details and amounts aloud in Nepali (`ne-NP`).
- **Transaction History**: Keeps track of received and sent transaction records.
- **Multilingual & Localization**: Includes support for Nepali language strings and custom themes.
- **Settings & Preferences**: Configurable notification listeners, voice announcements, and appearance settings.

## Tech Stack
- **Kotlin & Coroutines**
- **Android SDK & NotificationListenerService**
- **TextToSpeech Engine**
- **Material Design UI Components**
